# Экстры — Fate Toolkit 1.50.0-preview.5

Статус: первое встроенное испытательное ядро. Открывается в кастомной анкете персонажа, раздел «Экстры». Старые предметы `Item / Extra` остаются совместимы: все программируемые правила располагаются в `flags.fate-aspect-widget.extraDefinition`; счётчики применения — отдельно в `flags.fate-aspect-widget.extraRuntime`.

## Использование

1. GM нажимает «Создать» или «Конструктор механики» на существующей экстре.
2. Указывает название, иконку, описание, тип (активная, пассивная, комбинированная), необязательную стоимость Волей. В раскрываемой части «Механические эффекты» добавляет нужное число операций.
3. После сохранения активная экстра запускается кнопкой «Использовать». Значок захвата рядом с ней перетаскивается на штатную нижнюю панель макросов Foundry, создавая макрос для этой экстры этого персонажа.
4. Пассивный бонус к броску учитывается автоматически в бросках Fate Toolkit, как на стороне игрока, так и при проверке результата ведущим. Пассивное состояние показывается без нажатия. Состояния, создаваемые активной экстрой, отображаются в анкете.
5. Экспорт одной или всех конструкторских экстр показывает JSON для копирования. Импорт принимает JSON текстом или из файла, поддерживает пакет до 40 экстр. Перед записью показывает имена и количество эффектов. Старые предметы не заменяются без явного удаления.

## Доступные операции

- Модификатор броска (+/-), ограниченный действием Fate и необязательным названием навыка.
- Изменить запас Воли (в пределах шкалы).
- Создать аспект сцены (с начальными бесплатными призывами).
- Добавить бесплатные призывы к существующему аспекту сцены по имени.
- Наложить временное или постоянное отображаемое состояние.
- Увеличить/уменьшить именованный счётчик использования.

## Текущие границы

- Для пассивных экстр механически исполняются **только модификаторы броска** и постоянные отображаемые состояния. Остальные операции требуют активной экстры; редактор отклонит неисполняемый пассивный тип.
- У комбинированных экстр модификаторы броска действуют пассивно; состояния и другие операции активируются кнопкой.
- Теги могут сохраняться в конфигурации, но автоматическое применение условных эффектов с тегами намеренно не запускается без машиночитаемого контекста. В редакторе ни одно действие игрока не требует назначать тип атаки вручную.
- Длительность «до конца сцены» относится к **повествовательной сцене** Fate Toolkit и её номеру; смена карты сама по себе сценой не считается.
- Состояние пока информационное; сложные условные механики, последствия, длительности по числу срабатываний, реактивные триггеры и ветвления требуют следующей итерации.
- Запуск внутри Foundry VTT в живой игре не проверен. Автономные тесты покрывают формат, импорт, активное применение, дедупликацию, права и базовый пассивный бонус, но не взаимодействие браузера / DOM Foundry.
- Перед установкой на основной мир необходимо создать его резервную копию.
